Version 1.0
über localhost 8080 erreichbar, siehe http://localhost:8080
Patient wird hinzugefügt über patientliste und danach patient hinzufügen
Geräte werden hinzugefügt über geräteliste und danach gerät hinzufügen
Reservierungen werden hinzugefügt über reservierungsliste und danach reservierung hinzufügen. Man muss zuerst Patient auswählen, den Datum und das gerät auswählen und dann auf reservierung hinzufügen klicken. Danach wird die Reservierung in der Reservierungsliste angezeigt
Bei Patienten werden neue SVNRs automatisch generiert, bei Geräten neue Seriennummern
